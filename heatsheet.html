⚙️ Creation of Heat Sheet — Backend Steps

StepBackend ActionOutput
1Lock entries for the tournamentNo more booking edits
2Pull all paid/approved bookingsMaster player list
3Expand bookings event-wiseOne row per swimmer per event
4Group by category + gender + eventEvent-wise entry pools
5Sort by seed time (NT entries last)Seeding order list
6Assign heats and lanes (fastest in centre)Heat sheet data with each Heat Start time
7Calculation of Estimated Time CompletionDisplay by Website to arrive Completion time of Event
8Review / manual adjustAdmin correction stage
9Publish heat sheet PDF/web pageFinal heat sheet
ⓘ Our backend should not generate heat sheets directly from the player profile table. It should use a separate event-entry table where each selected event becomes its own row.
ⓘ No. of Lanes is editable (6 or 8 or 10). Accordingly the lane assignment pattern and Heat Sheet will be regenerated.
